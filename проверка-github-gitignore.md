## 7. Проверка для преподавателя (как повторить)

```bash
git clone https://github.com/issakhanovae-create/my_site.git
cd my_site
git log --oneline
# ожидается один коммит: abfb679

git ls-files .env data/crm.db
# пусто

git rev-list --objects HEAD | findstr /i "exports .env crm.db"
# пусто (или без совпадений по секретам/exports)

type .gitignore
```

Открыть на GitHub: убедиться, что есть `.env.example`, нет `.env`, есть `src/`, `server.cjs`, `Dockerfile`.
